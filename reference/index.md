# Package index

## All functions

- [`amp_acro()`](https://docs.ropensci.org/GLMMcosinor/reference/amp_acro.md)
  : Used to specify a cosinor component in the model formula.

- [`autoplot(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/autoplot.cglmm.md)
  : Plot a cosinor model

- [`autoplot_data_processor()`](https://docs.ropensci.org/GLMMcosinor/reference/autoplot_data_processor.md)
  : Process data for autoplot

- [`cglmm()`](https://docs.ropensci.org/GLMMcosinor/reference/cglmm.md)
  :

  Fit cosinor model with [glmmTMB](https://github.com/glmmTMB/glmmTMB)

- [`cosinor_mixed`](https://docs.ropensci.org/GLMMcosinor/reference/cosinor_mixed.md)
  : cosinor_mixed dataset for cosinor modeling examples.

- [`fit_model_and_process()`](https://docs.ropensci.org/GLMMcosinor/reference/fit_model_and_process.md)
  :

  Fit the cosinor GLMM model using the output from
  [`update_formula_and_data()`](https://docs.ropensci.org/GLMMcosinor/reference/update_formula_and_data.md)
  and a new formula

- [`get_background_grid()`](https://docs.ropensci.org/GLMMcosinor/reference/get_background_grid.md)
  : Create the background for a polar plot.

- [`get_point_estimate_plot()`](https://docs.ropensci.org/GLMMcosinor/reference/get_point_estimate_plot.md)
  : Add a ellipses layer to a polar plot.

- [`polar_plot()`](https://docs.ropensci.org/GLMMcosinor/reference/polar_plot.md)
  : Generates a polar plot with elliptical confidence intervals

- [`polar_plot(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/polar_plot.cglmm.md)
  : Generates a polar plot with elliptical confidence intervals

- [`predict(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/predict.cglmm.md)
  : Predict from a cosinor model

- [`print(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/print.cglmm.md)
  :

  Print a brief summary of the `cglmm` model.

- [`print(`*`<cglmmSubTest>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/print.cglmmSubTest.md)
  : Print test of model

- [`print(`*`<cglmmSummary>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/print.cglmmSummary.md)
  : Print the summary of a cosinor model

- [`print(`*`<cglmmTest>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/print.cglmmTest.md)
  : Print results of test of cosinor model

- [`sigma(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/sigma.cglmm.md)
  : Extract residual standard deviation or dispersion parameter

- [`simulate_cosinor()`](https://docs.ropensci.org/GLMMcosinor/reference/simulate_cosinor.md)
  : Simulate data from a cosinor model

- [`sub_ggplot.cglmm.polar()`](https://docs.ropensci.org/GLMMcosinor/reference/sub_ggplot.cglmm.polar.md)
  : create a (sub) polar plot (iterated over for each component)

- [`summary(`*`<cglmm>`*`)`](https://docs.ropensci.org/GLMMcosinor/reference/summary.cglmm.md)
  : Summarize a cosinor model Given a time variable and optional
  covariates, generate inference a cosinor fit. Gives estimates,
  confidence intervals, and tests for the raw parameters, and for the
  mean, amplitude, and acrophase parameters. If the model includes
  covariates, the function returns the estimates of the mean, amplitude,
  and acrophase for the group with covariates equal to 1 and equal to 0.
  This may not be the desired result for continuous covariates.

- [`test_cosinor_components()`](https://docs.ropensci.org/GLMMcosinor/reference/test_cosinor_components.md)
  : Test for differences in a cosinor model between components.

- [`test_cosinor_levels()`](https://docs.ropensci.org/GLMMcosinor/reference/test_cosinor_levels.md)
  : Test for differences in a cosinor model between levels of the
  grouping variable.

- [`update_formula_and_data()`](https://docs.ropensci.org/GLMMcosinor/reference/update_formula_and_data.md)
  : Update data and formula for fitting cglmm model

- [`vitamind`](https://docs.ropensci.org/GLMMcosinor/reference/vitamind.md)
  : Vitamin D dataset for cosinor modeling examples.
